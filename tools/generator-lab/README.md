## 評価文の編集改善（2026-09-04）

`Render.bodyLines` を画像の描画と編集欄で共用する。編集欄に表示する自動改行と原稿の文字位置の対応を `review-projection.mjs` が管理し、自動改行は原稿への保存・コピーに混入させない。Enterで入れた改行は原稿に残して画像にも反映する。置換対象のカーニングだけを除き、後続文字の設定は位置をずらして維持する。評価文内での取り消し・やり直しは100操作分を保持する。

ネイティブのテキスト欄は画像と同じ改行位置で編集できる。Canvas独自の均等割り付け・句読点の詰めまでネイティブ入力欄の文字座標を一致させる実装ではない。厳密な文字位置は同じ出力Canvasから切り出した拡大表示で確認する。改行位置を保ったまま全文が見えるよう、評価文欄の文字サイズを表示幅に合わせて自動調整する。横スクロールは不要。本文拡大用に別途約1.9MiBのCanvasを使用する。

## 選択範囲の字間（Mixed）

「行送りの上限」と「字間」を横並びにする。両方の数値はダブルクリックで符号・小数点を含めて全選択でき、そのまま入力して置き換えられる。

字間欄は原稿の選択範囲に対応し、本文全体のtrackingと各文字の追加調整kernsを合算した値を表示する。複数の値があればMixedを表示。数値入力では加算せず、選択範囲の実効字間をその値に統一する。範囲外の文字は変えない。選択がない場合は本文全体を対象とする。自動改行は文字として数えず、明示改行の位置も字間比較から除く。字間操作も評価文の取り消し対象に含める。

表示チェックは見出し直後（7pxの間隔）、見出しの文字サイズと同じ13px角に変更した。

`node --test tools/generator-lab/test/spacing-check.mjs` でMixed判定・範囲内の絶対値指定・範囲外の維持・ゼロ設定・全体適用の3テストが成功。Chromium画面でもMixed→直接入力→同値表示、範囲外0%維持、符号を含む数値のダブルクリック全選択、390px幅の配置を確認した。

## 選択表示の継続と全項目の文字調整

作品名・アーティスト名・曲数と総尺・ジャンル・国・おすすめ曲番号／曲名・評価文を共通の調整欄で操作する。「調整対象」に現在の項目と選択範囲を表示する。

| 操作 | 選択表示と適用先 |
| --- | --- |
| 文字を選択する | 字間はその範囲へ適用。範囲内に異なる値があればMixed |
| 字間・行送り欄へ移動、数値を変更 | 青い選択表示を維持。プレビュー更新でも解除しない |
| Enterまたは「調整を確定」 | 選択を解除。数値変更は既にプレビューへ反映されている |
| 別の文字を選択／他の項目へ移動 | 新しい選択・項目へ切り替える |
| 元の文字欄・調整欄の外をクリック、またはTabで外へ移動 | 選択を解除 |
| 元の文字欄の選択範囲外をクリック | 通常のカーソル移動として選択を解除 |
| 選択がない状態で字間を入力 | 現在の文字欄全体へ適用 |

行送りは常に文字欄全体へ適用する。1行だけの文字では見た目は変わらない。自動プレビュー更新と確定を分け、数値を複数桁入力する途中で対象が全体へ変わらないようにした。選択の青色は編集用の表示で、PNGには含まれない。

評価文以外は `slot.typography[field] = {tracking, kerns, leading}` に項目ごとの調整値を保持する。本文は既存の `tracking`・`kerns`・`bodyMaxLead` を継承する。文字を置換した際は範囲外のカーニング位置を追従させる。評価文の取り消し履歴には字間・行送りを含める。他の項目の書式変更を取り消す履歴UIは未接続。

曲数・総尺／ジャンル／国とおすすめ曲の画像内の左右余白は、本文と同じ25px（1200px基準）。中黒と文字の間隔は通常50pxから必要に応じて0pxまで縮める（25px未満も許可）。左右余白25pxは維持し、負の間隔にはしない。2400px出力ではすべて2倍になる。字間・フォントサイズは自動では変更しない。最小間隔でも横幅または高さを超えると警告してPNG生成を停止し、字間・改行・表示項目の調整を促す。作品名・アーティスト・本文も同じ描画計算で溢れを検出する。

最小間隔25pxの時点では掲載サンプルの上下とも幅が不足したため、ユーザーの指示で最小間隔を0pxへ変更した。文字の左右余白を保ったまま、中黒との間隔を25px未満へ縮めて収められる。文字自体が利用可能幅を超える場合は引き続き警告する。
